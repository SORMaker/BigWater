# Big Water 0.4.0

- 新增 Sparkle 自动更新：每天检查一次新版本，可在设置面板关闭，也可以随时点击“检查更新…”。
- 后台发现新版本时在菜单栏显示提示点，打开设置即可查看，不抢走其他窗口的焦点。
- 发现新版本后可直接下载、安装并重新打开，无需手动替换 App；默认安装前由你确认。
- 更新包和版本信息均使用 Ed25519 签名验证，喝水记录和提醒设置继续保存在本机。
- 发布包同时支持 Apple 芯片和 Intel Mac，要求 macOS 13 或更高版本。

0.3.0 及更早版本请先下载 ZIP，退出旧版，将解压后的 Big Water.app 放入“应用程序”文件夹。之后即可使用 App 内更新。

本发布包尚未经过 Apple Developer ID 签名和公证，首次打开时 macOS 可能要求在“隐私与安全性”中确认打开。
