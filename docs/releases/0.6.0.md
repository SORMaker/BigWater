# Big Water 0.6.0

- 点“去喝水”后，小人不再马上离开：它停下扔瓶子，举起水瓶陪你喝 20 秒，进度走完才记一次喝水。顺手点掉换不来清净；喝到一半点“稍后”则不记录。面板和右键菜单里的“去喝水”同样要等 20 秒走完。
- 离开座位自动暂停：键盘、鼠标和触控板超过 5 分钟没有操作时停止计时，回来后接着剩余时间继续；播放视频或演示时照常计时。可在齿轮中关闭，或改为 3、10、15 分钟。
- 新增三个角色：戴尖帽子、用法杖变出水瓶的魔法师，等水时会蔫掉、喝上水才开花的仙人掌，一边浮动一边喷水的小鲸鱼。角色改为点头像选择。
- 扔出的水瓶不再只落在身边几处，每瓶随机砸向前方的地面、对面墙或天花板，在撞到的地方溅开。
- 暂停期间缩短提醒间隔时，倒计时会同步缩短。
- 内部代码整体重写，设置、倒计时和喝水记录原样保留。
