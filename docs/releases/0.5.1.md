# Big Water 0.5.1

- 无需等待提醒，随时在面板或菜单栏右键菜单记录喝水，并从此刻重新计时。
- 可以撤销刚才的误记，恢复原倒计时；之后做过的暂停、延后、间隔和作息调整会保留。
- 记录页改为按月热力图，每格一天；点击日期查看时间，并可删除误记，继续保留最近 90 天的本机记录。
- 菜单栏右键新增记录、撤销、暂停 30/60 分钟、恢复计时和打开设置。
- 提醒可选择随机出场或固定四角；支持鼠标所在屏幕、主屏幕及指定显示器。指定显示器断开时暂用主屏幕，保留原选择。
- 作息支持多个不重叠时段，休息间隔保留剩余进度，下一时段继续计时；工作日和周末可分别设置，旧作息继续保留。
- 喝水记录可以补记和修改时间，保存后同步更新热力图；历史更正不会重置计时或确认提醒。
- 保留原来的菜单栏像素水瓶，可开启剩余分钟文字，同时显示暂停、待确认、休息和今天不再提醒的状态。
- 保留像素风和原来的面板水瓶，调整卡片配色、边线和信息层次；作息调整支持一次编辑多个时段后保存。
