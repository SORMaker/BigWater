# Big Water · 大水

我的一个 vibe coding 小项目：原生 macOS 菜单栏喝水提醒。像素角色从屏幕上方滑下来提醒喝水，也可以换成安静的角落卡片。

- 默认每 **2 小时**提醒，可在 **0.5–24 小时**之间按半小时调整。菜单里实时显示剩余倒计时、下次提醒时间和当前状态。
- 角色提醒时显示像素风 **“我刚喝过水”** 按钮。点击立即保存一次喝水确认、开始下一轮计时，角色挥手后爬回去。点角色本身只收起提醒并重新计时。
- 可以选择 **10／20 分钟后再提醒**。延后期间休眠也会暂停，不改变常规提醒间隔。
- 开会或专注时可 **暂停 30／60 分钟**，保留剩余进度，到点自动恢复，也可手动提前恢复。
- 默认按电脑的 **本地时间 06:00–22:00** 运行，可设置每天的开始／结束时间，也可为周末设置单独作息。作息结束时收起提醒，次日首次使用开始完整间隔。
- **系统休眠、显示器熄屏、切换到其他用户时暂停**，同日恢复使用后接着剩余时间。离线时间不计入倒计时。
- **保存当天进度**：正常退出前保存；计时期间每 30 秒保存一次检查点。重新打开可恢复倒计时、延后和暂停状态；异常退出从最近保存的检查点恢复。
- **两种提醒方式**：角色动画、轻量像素卡片。声音默认关闭，可独立开启。
- **角色与外观**：Claude／水滴，海蓝／薄荷／蜜桃配色。设置页可以预览当前效果，预览不改变正式计时、不记录喝水。
- **今日记录**：只记录“我刚喝过水”的明确确认和时间，只保存在本机。关闭角色、延后或预览都不会增加记录，不估算饮水量。
- 默认启用 **登录时启动**，可以关闭。若 macOS 要求批准，设置页提供系统登录项入口。
- Dock 不显示图标，提醒不抢键盘焦点。绳子、水瓶和透明区域允许鼠标穿透；角色和按钮接收点击，轻量卡片和对话气泡会挡住点击，不会误点到下面的窗口。多显示器时出现在鼠标所在屏幕。

默认 22:00 截止是个人作息偏好，用于减少睡前打扰。

## 运行

需要 macOS 13 或更高版本、Xcode Command Line Tools；没有第三方依赖。

```sh
./Tools/build.sh
open "dist/Big Water.app"
```

生成的 App 位于 `dist/Big Water.app`，可直接双击，也可以拖到“应用程序”。登录启动使用 macOS 的 `SMAppService`；移动 App 后，可重新开关一次登录启动。

设置页的“预览当前效果”只展示外观。开发时要走完整提醒与确认流程，可以先退出已运行的 App，然后运行：

```sh
./Tools/run.sh --preview
```

`--preview` 会在当前作息窗口内提前发起一次真实提醒，点击喝水按钮会记录确认。提醒中的外观修改在下次提醒生效。

## 验证与代码

```sh
swift run BigWaterChecks
./Tools/check-session.sh
```

核心检查覆盖休眠续计、跨日、作息与周末窗口、校时和时区、进度恢复、暂停、延后、记录及像素动画。会话检查直接运行实际 App 类，在隔离偏好域里发送进程内通知，核对窗口、按钮、计时和保存的连接；需要亮屏的 macOS 桌面会话。检查不会让电脑休眠或修改系统时间。

`BigWaterCore` 管理计时、配置、记录和动画状态，`BigWaterArt` 绘制像素角色、水瓶及配色，`BigWater` 管理菜单栏、设置、保存和桌面窗口。`BigWaterArtwork` 生成图标与动作预览。构建输出还包括 `dist/Artwork/storyboard.png` 与 `animation.gif`，复用实际 App 的绘制代码。
