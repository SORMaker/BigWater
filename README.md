# Big Water · 大水

我的一个 vibe coding 小项目：原生 macOS 菜单栏喝水提醒。Claude 戴蓝色像素帽，沿绳子从屏幕上方滑下来，持续扔大瓶矿泉水。点一下 Claude，他会停止扔水，挥挥手，再沿绳子爬回去。

- 默认每 **2 小时**提醒，设置范围为 **0.5–24 小时**，每次调整半小时。
- 菜单栏图标是一瓶蓝色像素矿泉水。点击图标可调整提醒间隔、设置登录启动或退出。
- Dock 不显示图标。提醒不抢键盘焦点，绳子、水瓶和水花允许鼠标穿透；角色区域接收点击。
- 下一次提醒从**点击 Claude 的时刻**重新计时。修改间隔立即保存；如果 Claude 正在提醒，新间隔从这次点击后生效。
- 按电脑的**本地时间 06:00–22:00**运行。早晨首次亮屏使用后开始计时；06:00 前不计时，22:00 起停止计时并收起提醒。
- **系统休眠、显示器熄屏、切换到其他用户时暂停**，当天恢复使用后接着剩余时间计时。例如已计时 45 分钟，休眠 3 小时，唤醒后仍剩 75 分钟。
- **次日重新开始完整间隔**，不会在早上补发昨晚的提醒。当天剩余使用时间不足一个间隔时，不再提醒。
- 自动跟随系统时区；倒计时使用单调时钟，不因手动校时突然多算或少算几小时。
- 默认启用**登录时启动**，可以在设置中关闭。若 macOS 要求批准，设置页会提供系统登录项入口。
- 多显示器时，提醒出现在鼠标所在的屏幕。动画只在提醒期间运行。

22:00 是个人作息偏好，用于减少睡前打扰。

## 运行

需要 macOS 13 或更高版本，以及 Xcode Command Line Tools。没有第三方依赖。

```sh
./Tools/build.sh
open "dist/Big Water.app"
```

生成的 App 位于 `dist/Big Water.app`，可直接双击，也可以自行拖到“应用程序”。

立即体验提醒（先退出已运行的 Big Water）：

```sh
./Tools/run.sh --preview
```

`--preview` 在 06:00–22:00 内提前触发一次提醒，不修改保存的提醒间隔。点击角色会走正常的收场与计时逻辑。App 保持运行时才会计时；主动退出后再次打开会从完整间隔开始。登录启动使用 macOS 的 `SMAppService`，请保留 App 所在的位置；移动 App 后可重新开关一次登录启动。

## 动作与验证

人物手绘在固定像素网格上，具有四条小腿、蓝色帽子、交替攀绳的手、蓄力与出手的手臂、眨眼和点击后的挥手。水瓶带瓶盖和 H₂O 标签，飞行中旋转、变大，落出屏幕后留下短暂像素水花。画面以 Claude 的陶土橘、奶油色和水的蓝色为主。

```sh
swift run BigWaterChecks
./Tools/check-session.sh
```

检查覆盖休眠续计、重复系统通知、跨日重置、06:00/22:00 边界、夜间收起提醒、系统校时、切换时区、夏令时、熄屏登录启动、点击后重新计时、设置修改，以及动画与点击区域。独立检查程序可以在未安装 XCTest 的 Command Line Tools 环境下运行。构建还会生成 `dist/Artwork/storyboard.png` 与 `animation.gif`，使用与实际 App 相同的绘制和动画代码。

`check-session.sh` 需要亮屏的 macOS 桌面会话。它在独立进程中运行实际 App 类，并发送进程内的系统通知，验证暂停、恢复、跨夜角色清理和夜间停止；不会让电脑休眠或修改系统时间。

代码分为三个部分：`BigWaterCore` 管理计时与动画状态，`BigWaterArt` 绘制像素角色和水瓶，`BigWater` 管理菜单栏、设置和透明桌面窗口。`BigWaterArtwork` 生成图标与动作预览。
